# playnook
Ecossistema open source em Java para criar jogos 2D originais, com controles compartilhados, suporte a traduções e distribuição inicial em ZIP.

## Sobre o nome

Playnook combina “play” — jogar — com “nook”, palavra em inglês para um cantinho ou espaço acolhedor: o nome representa um cantinho para criar e jogar. Há também uma piscadinha intencional para “nuke”, termo conhecido no universo dos games e associado a explosões e ação. “Nook” e “nuke” são palavras diferentes; a associação com “nuke” é apenas um trocadilho complementar, não o significado literal de “nook”.
